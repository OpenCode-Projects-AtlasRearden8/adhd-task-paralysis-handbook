# Start Here

**The ADHD Task Paralysis Handbook** — a gentle, low-shame manual for getting
unstuck when a task simply will not start.

## Who this is for

This is for anyone who has ever sat in front of a task — an email, a load of
dishes, a form, a phone call — and *could not start it*. Not "didn't want to."
Not "was lazy." **Could not.** The task sits there like a wall. The longer you
stare at it, the heavier it gets, and the shame of not starting makes the wall
taller.

If that's you, you're in the right place. This handbook assumes:

- You are not broken. Task paralysis is a motivation-and-starting problem, not a
  character problem.
- You don't need more discipline. You need smaller doorways.
- Nothing here is mandatory. Take what works, leave the rest.

## How to use this manual

1. Don't read it front to back. You won't. That's fine.
2. Skim chapter titles. Pick the one that made you wince slightly.
3. Try exactly one tool today. One.
4. If it doesn't work, that counts as data, not failure.

## The one rule

**Never use any tool in this book to bully yourself.** If a timer, checklist, or
AI nudge starts sounding mean, it has failed. Get rid of it. The goal is to make
starting *cheaper*, not to make you feel worse.

---

*This is education and practical tooling, not medical advice. If task
paralysis is seriously affecting your life, a doctor or therapist who
understands ADHD is a far better resource than any handbook — this one
included.*
